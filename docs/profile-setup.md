# Настройка под себя

Этот файл отвечает на главный вопрос: что заполнить, чтобы бот работал как инструмент фрилансера, а не писал случайную ерунду.

## 1. Где что настраивать

### `.env`

Технические ключи и режимы:

- `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` — чтобы читать Telegram-источники.
- `TELEGRAM_BOT_TOKEN` — чтобы бот присылал лиды.
- `AI_REPLY_ENABLED=true` — включает генерацию откликов по кнопке.
- `OPENAI_API_KEY` — нужен только для кнопки **Сделать отклик**.
- `FREELANCER_PROFILE_PATH=freelancer_profile.json` — путь к вашему профилю.

### `freelancer_profile.json`

Главный файл фрилансера. Его нужно создать из примера:

```bash
cp freelancer_profile.example.json freelancer_profile.json
```

В нём заполняются:

- кто вы;
- какие услуги берёте;
- какой стек знаете;
- какие кейсы можно честно упоминать;
- каким тоном писать;
- какие слова, фразы и знаки не использовать;
- какие проекты не брать.

### `config/filters.json`

Фильтр до OpenAI API. Здесь решается, какие посты вообще попадут в Telegram.

- `keywords` добавляют score. Число рядом с фразой — её вес.
- `stop_words` сразу отклоняют мусор.
- `min_score` задаёт строгость фильтра.

Если API тратится на плохие лиды, сначала правьте `config/filters.json`, а не prompt.

### `config/sources.json`

Список Telegram-каналов, которые бот читает.

Если источник даёт мусор, его лучше отключить или заменить.

## 2. Пример профиля frontend-разработчика

Минимально нормальный профиль:

```json
{
  "name": "Алексей",
  "positioning": "Frontend-разработчик. Делаю сайты, лендинги, интерфейсы и небольшие веб-приложения.",
  "services": [
    "адаптивные сайты и лендинги",
    "верстка по Figma",
    "React/Next.js интерфейсы",
    "формы заявок и квизы",
    "интеграция с API"
  ],
  "stack": ["HTML", "CSS", "JavaScript", "TypeScript", "React", "Next.js", "Tailwind CSS"],
  "cases": [
    {
      "title": "Лендинг для услуги",
      "result": "Собрал адаптивную страницу с формой заявки и понятным CTA."
    }
  ],
  "tone": "Коротко, спокойно и по делу. Без давления и громких обещаний.",
  "banned_punctuation": ["—", ":"],
  "banned_phrases": [
    "имею большой опыт",
    "готов взяться прямо сейчас",
    "сделаю качественно и в срок"
  ]
}
```

## 3. Как запретить плохой стиль

Используйте поля:

- `banned_words` — отдельные слова, например `эксперт`, `гарантирую`.
- `banned_phrases` — шаблонные фразы, например `ваш проект мне очень интересен`.
- `banned_punctuation` — знаки, которые нельзя использовать, например длинное тире `—` или двоеточие `:`.
- `style_rules` — правила поведения, например `Не писать длиннее 900 символов`.
- `examples.good_reply` — пример нормального ответа.
- `examples.bad_reply` — пример ответа, на который не надо быть похожим.

## 4. Как проверить отклик без Telegram

После заполнения `.env` и `freelancer_profile.json` можно прогнать тестовый заказ:

```bash
uv run --frozen python -m freelancer_bot --draft-text "Нужно сверстать лендинг по Figma на React, адаптив, форма заявки в Telegram. Бюджет обсуждаем."
```

Эта команда вызывает OpenAI один раз и печатает:

- fit score;
- краткий разбор;
- риски;
- вопросы клиенту;
- короткий отклик;
- полный отклик.

Так удобно крутить профиль, пока ответы не станут похожи на ваш стиль.

## 5. Как проверить фильтр без API

```bash
uv run --frozen python -m freelancer_bot --check-filter "Нужно сверстать сайт по Figma на Next.js, есть ТЗ и бюджет"
```

Если хороший заказ не проходит, добавьте нужные слова в `keywords` или снизьте `min_score`.

Если мусор проходит, добавьте слова в `stop_words` или поднимите `min_score`.

Проверить оба JSON-файла разом:

```bash
uv run --frozen python -m freelancer_bot --check-config
```

Проверить доступность включённых Telegram-источников через пользовательскую сессию:

```bash
uv run --frozen python -m freelancer_bot --check-sources
```

## 6. Как не тратить API зря

Правильный порядок такой:

1. Настроить источники в `config/sources.json`.
2. Настроить `keywords`, `stop_words`, `min_score` в `config/filters.json`.
3. Проверить фильтр через `--check-filter`.
4. Проверить источники через `--check-sources`.
5. Запустить бота и посмотреть качество лидов.
6. Только потом включить `AI_REPLY_ENABLED=true`.

OpenAI должен писать отклики только на лиды, которые уже прошли локальный фильтр и которые вы выбрали кнопкой.
